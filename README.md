# pyRfactor2SharedMemory
Python library for accessing TheIronWolf's [rF2 Shared Memory Map Plugin](https://github.com/TheIronWolfModding/rF2SharedMemoryMapPlugin) interface for rFactor 2.

## What's new
This forked version adds various new features, such as cross-platform support, type hints & annotations, standard naming convention, with some features backported from [pyLMUSharedMemory library](https://github.com/TinyPedal/pyLMUSharedMemory).
